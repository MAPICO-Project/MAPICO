# 작업 기록 (worklogs)

기록 규칙은 하나로 통일한다.

- 파일명: `YYYY-MM-DD_주제.md`. 계획과 결과를 나누면 `_PLAN` / `_RESULT` 접미를 붙인다. 한글 주제도 된다.
- 내용: 작업마다 **무엇을 / 왜 / 검증 / 미검증**을 3~5줄로 적는다.
- 다 끝나 더 참고하지 않는 기록은 지운다. 지운 파일은 git 이력(`git log --all -- <경로>`)에서 되찾을 수 있다.
- 현재 인계는 [SESSION_HANDOFF.md](SESSION_HANDOFF.md) 한 곳만 갱신한다.

새 계획도 이 폴더에 `_PLAN`으로 쓴다.
