## 0. GNB

- [홈] — [디지털 옷장] — [스타일 믹스 · 캘린더] — [소셜 피드]
- 마이페이지: 홈 우측 상단 프로필 아이콘에서 진입, GNB 제외

## 1. 진입·온보딩

1. 앱 실행 → 스플래시
2. 로그인 상태인가?
   - 아니오 → 로그인/회원가입(카카오 소셜 로그인)
3. 신규 회원인가? 예 → 자신의 추구미를 알고 있는가?
   - **예** → 메인 추구미 선택 1개(페미닌·Y2K·미니멀·그런지·캐주얼) → 보조 추구미 선택 0~2개
   - **아니오** → 무드보드 탐색 → 코디 카드 선택
     - 조건: 총 15~20장, 5개 추구미별 3~4장, 최소 3장/최대 6장 선택
     - 카드 1장마다 내부 추구미 +1, 라벨 비노출
     - 최고 점수 = 메인, 차순위 = 보조
     - 추구미 간 유사도 MVP 미고려
     - → 추구미 분석 중 → 동점?
       - 예 → Tie-break(대표 이미지 1~2장 중 더 선호 선택)
4. 추구미 결과(메인 1 + 보조 0~2)
   - 직접 수정하기(메인/보조 재선택)
   - 이대로 시작하기
5. 원샷 옷장 등록 안내: 옷 여러 벌을 바닥에 펼쳐 한 장 찍으면 AI가 각각 분리 등록. 예시 화면 안내만, 실제 촬영/등록 없음
6. → 홈

## 2. 홈

- 오늘의 날씨: 현재 위치·기온
- 추구미 선택: 메인 1 + 보조 1~2, 기본 = 메인, Chip 선택 시 Reload
- 옷장 아이템 충분한가?
  - 아니오 → 추천 코디 생성 불가("옷장을 채우면 추천을 받을 수 있어요")
  - 예 → AI 추천 코디 총 3개([1/3] ↔ [2/3] ↔ [3/3])
    - 내용: 내 옷장 아이템 조합·선택 추구미·현재 날씨·AI 추천 이유
    - AI 추천 코디 Reload
    - 행동: 코디 보관함에 저장 / 스타일 믹스 / 오늘 입기
- 프로필 아이콘 → 마이페이지

## 3. 디지털 옷장

- 옷장 갤러리: 전체·아우터·상의·하의·신발·가방·액세서리, Grid, 카테고리 필터
- 의류 상세: 누끼·원본·카테고리·비고. 색상/추구미 자동 태그 없음
- **+ 옷 등록** → 등록 방식
  - 원샷 촬영 → 카메라 권한?
    - 없음 → 설정으로 이동
    - 있음 → 촬영 → 확인
  - 앨범에서 가져오기 → 시스템 갤러리 → 이미지 선택
  - → 이미지 확인 → AI 분석 중(다중 검출·개별 분리·배경 제거·카테고리 분류) → 성공?
    - 아니오 → 분석 실패(다시 시도 / 이미지 재선택)
    - 예 → 분석 결과 검토(각 의류 누끼 + 카테고리) → 아이템 수정(카테고리 수정·비고 입력) → 내 옷장에 모두 저장 → 저장 완료

## 4. 스타일 믹스 · 캘린더

- **캘린더**: 월별 OOTD 캘린더(썸네일 + 저장 당시 날씨 아이콘) → 날짜 선택 → 기록 있음?
  - 예 → OOTD 상세(날짜·날씨·착용 의류·별점 1~5·메모·선택 사진)
    - 피드에 공유 → 포스트 작성
    - 수정 → OOTD 수정
    - 삭제 → 삭제 확인
  - 아니오 → OOTD 기록 작성(아이템 확인 → 별점 → 메모 → 저장)
- **+ 추가** → 코디 조합(옷장 아이템 다중 선택, 리스트/그리드, 카테고리) → 조합 완료 → 코디 보관함
- **통계**: 옷장 활용도 통계, 최다 추구미·아이템 Top 3, 30일 이상 미착용 아이템
- **정의**
  - 코디 보관함 = 아직 입지 않아도 저장한 조합
  - OOTD 캘린더 = 특정 날짜에 실제로 입은 착장 기록

## 5. 소셜 피드

- 필터: 추구미(전체·페미닌·Y2K·미니멀·그런지·캐주얼), 날씨(맑음·흐림·비·눈·바람)
- Feed Reload
- OOTD Masonry Feed(Pinterest Style Grid) → 포스트 상세(사용자·일시·추구미/날씨·대표 이미지·연결 아이템·좋아요·따라입기)
  - 좋아요 → 좋아요 활성화 → 마이페이지 아카이브 저장
  - 내 옷장으로 따라입기 → AI Matching(Post 연결 Item ID ↔ 내 옷장 Item Vector, 대표 이미지를 다시 객체 검출하지 않음) → 전체 매칭률 0%?
    - 아니오 → 따라입기 결과(전체 매칭률·원본 ↔ 유사 아이템·아이템별 유사도 %) → 코디 보관함에 저장
    - 예 → "비슷한 옷이 없음, 옷장을 조금 더 채워보세요" → 옷 등록하기
- **+ 포스트 작성** → 업로드 출처
  - 캘린더 OOTD에서 가져오기(OOTD 선택, 사진/아이템/날씨 자동)
  - 갤러리 사진으로 작성(사진 선택 → 착용 아이템 선택)
  - 디지털 옷장 아이템 최소 1개 연결 필수(0개면 다음 버튼 비활성화)
  - → 포스트 작성(대표 사진·연결 아이템·추구미·날씨/온도·캡션) → 업로드
    - 완료
    - 실패(입력 유지·다시 시도)

## 6. 마이페이지

- 프로필 수정: 이미지 변경·닉네임 수정 → 저장
- 추구미 관리: 메인 1 + 보조 0~2, 저장 → 추천 데이터 업데이트
- 좋아요한 코디: Grid → 포스트 상세
- 내가 올린 포스트: 목록 → 상세 → 수정/삭제
- 계정 설정
  - 로그아웃: 확인 → 로그인 화면
  - 회원 탈퇴: 데이터 삭제 안내(디지털 옷장·OOTD·사용자 데이터) → 정말 탈퇴? 예 → 계정 및 데이터 삭제

## 7. 핵심 Cross Flow

- Ⓐ HOME 추천 → 코디 보관함
- Ⓑ HOME 추천 → 오늘 입기 → OOTD 캘린더
- Ⓒ HOME 추천 → 스타일 믹스
- Ⓓ OOTD 상세 → 피드 공유 → 소셜 피드
- Ⓔ 따라입기 → 보관함 / 매칭 0% → 디지털 옷장
