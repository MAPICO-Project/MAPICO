# 마피코(MyFit:Core) 모바일 웹 사용자 흐름

2026-09-28 최신 PRD 기준 **구현 예정 흐름**이다. 현재 배포된 health/readiness 점검 외에 아래 제품 API와 화면이 완성됐다는 뜻이 아니다. 실선은 제품 요구 연결, 점선은 미결 분기 또는 미구현 외부 연동이다.

## 1. 온보딩과 첫 사용

```mermaid
flowchart TD
  A[모바일 웹 접속] --> B[카카오 로그인]
  B --> C{추구미를 알고 있나요}
  C -->|예| D[5종 중 1~3개 선택]
  C -->|아니오| E[룩 이미지 탐색]
  E -. AI 점수 계약 미결 .-> F[추천 추구미 확인 또는 재선택]
  F --> D
  D --> G[예시 이미지 촬영 튜토리얼]
  G --> H[홈 진입]
  H --> I{옷장이 충분한가}
  I -->|아니오| J[등록 안내]
  I -->|예| K[날씨와 추구미 코디 조회]
```

첫 실물 촬영은 온보딩 완료 필수가 아니다. 대표+보조 가중치, 룩 이미지 수와 채점은 AI 합의 대상이다.

## 2. 다중 등록

```mermaid
sequenceDiagram
  actor U as 사용자
  participant W as 모바일 웹 예정
  participant B as BFF 예정
  participant S as 비공개 Storage
  participant A as AI Worker 예정
  U->>W: 겹치지 않은 2~6벌 촬영 또는 앨범 선택
  W->>B: 배치 생성과 업로드 URL 요청
  B-->>W: 서버 지정 signed upload
  W->>S: 이미지 직접 업로드
  W->>B: 업로드 완료 검증 요청
  B->>S: 실제 파일 검증
  W->>B: 분석 Job 생성
  B-->>A: 제한 URL 및 Job 전달
  A-->>B: 시도 번호와 lease로 결과 제출
  W->>B: 상태와 draft 조회
  B-->>W: 카테고리와 누끼 결과
  U->>W: 카테고리 수정 후 일괄 확정
  W->>B: 버전 포함 원자 확정
  B-->>W: 내 옷장 등록 완료
```

완전 실패만 재시도하며 부분 성공은 성공한 의류를 검토하거나 새 촬영으로 보완한다. 색상·추구미 편집은 최신 UI에서 제외한다. 원본 예측은 내부에 보존한다.

## 3. 보관·착용·공유

```mermaid
flowchart TD
  A[추천 코디] --> D[스타일믹스 의류 리스트]
  B[옷장 직접 선택] --> D
  C[따라입기 결과 확인] --> D
  D --> E{사용자 의도}
  E -->|나중에 재사용| F[날짜 없는 코디 보관함]
  E -->|특정 날짜 기록| G[날짜와 계획 또는 실제 착용 선택]
  F --> G
  G --> H[의류와 날씨 스냅샷 OOTD 저장]
  H --> I[실제 착용만 통계 반영]
  H --> J{공유할까요}
  J -->|예| K[공유 이미지와 태그 확인]
  K --> L[명시적 게시로 피드 공개]
  J -->|아니오| M[비공개 캘린더 유지]
```

보관함 편집으로 과거 기록을 변경하지 않는다. 하루1개는 현재 DB의 임시 제약이며 팀 결정 대상이다. 미래 날짜는 planned, 별점은 실제 착용 후 선택 입력으로 제안한다. OOTD 저장과 공개 동의를 분리한다.

## 4. 피드와 따라입기

```mermaid
flowchart TD
  A[추구미와 날씨 필터] --> B[현재 공개 피드]
  B --> C[게시물 상세]
  C --> D[좋아요와 아카이브]
  C --> E[내 옷으로 따라입기 요청]
  E -. 외부 AI 연동 예정 .-> F{매칭 결과}
  F -->|전체 또는 일부| G[후보와 부족 아이템 확인]
  F -->|후보 없음| H[옷 등록 CTA]
  G --> I[내 의류 선택을 확인]
  I --> J[별도 코디 보관 명령]
  C -. 비공개 또는 삭제 .-> K[새 조회와 URL 발급 차단]
```

매칭 점수는 확률이 아니다. 타인 의류 ID나 개인 원본 경로는 내 매칭 결과에도 노출하지 않는다. 원본이 비공개로 바뀌면 아카이브와 매칭 결과 조회에서도 가시성을 재확인한다.

- 05:00/07:00 사전 생성, 하루 여러 착장, 착장샷 독립 보관 정책은 미결이다.
- 신고/차단/모더레이션은 공개 테스트 범위와 함께 정해야 한다. 최신 PRD 필수로 임의 추가하지 않았으나 실제 공개 운영 전에 별도 검토가 필요하다.
