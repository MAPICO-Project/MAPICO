# 마피코 문서·임시 배포 작업 계획

기록일: 2026-09-28. 파일의 0000은 실제 작업 시각이 아닌 날짜 단위 기록용 자리표시자.

## 권한과 목표

사용자 요청: 최신 PRD와 회의 기록 정리, 프로젝트명 마피코 반영, Vercel/Supabase 임시 배포, 웹/앱 판단, 병렬 작업, 총정리.

## 병렬 분담

- 지휘·통합: 현재 메인 에이전트. 범위·권한·배포·검증 책임.
- 기존 문서 담당: 최신 PRD 정리와 이전 설계 대비 변경표. 기능 ID 및 미결 구분.
- Claude Opus 5.5 CLI: 기존 API/DB에 대한 독립적인 읽기 전용 배포 검토. 결과를 메인 에이전트가 확인한 뒤 반영.
- 메인 구현: 제품 API와 구분되는 최소 배포 검증용 백엔드, 테스트, Vercel 프리뷰 배포.

## 게이트

1. 사용자 제공 명칭 및 최신 명세를 정리한다. 구안과 회의 제안을 확정 사항으로 혼합하지 않는다.
2. 플랫폼은 미확정으로 기록하되 이번 임시 배포는 모바일 웹을 지원할 HTTP 백엔드 검증으로 한정한다.
3. Vercel 인증 확인, Supabase 인증 및 정확한 대상 프로젝트 확인.
4. 미인증·미구현 기능을 성공으로 위장하지 않는 최소 서비스를 배포한다.
5. 최신 PRD와 불일치하는 기존 SQL은 원격에 성급히 적용하지 않는다. 스키마 수정과 검증 후 별도 적용한다.
6. 테스트 결과와 배포 URL, 미완료·차단 사유를 총정리에 남긴다.

## 모델 확인

Claude CLI 2.1.278에서는 claude-opus-5-5 호출이 버전 부족 오류로 실패했다. 2.1.283으로 업데이트 후 실제 모델 claude-opus-5-5의 응답 성공을 확인했다. 내장 에이전트 모델과 외부 CLI 모델은 별도 경로다.
