# 프로젝트 착수 준비

## 목적

최종 제안서를 기반으로 MyFit:Core 프로젝트의 MVP와 개발 착수 조건을 확정합니다.

## 준비 완료

- AI CCTV 프로젝트의 문서 분할, 계획서 명명, 데이터·모델·산출물 분리 원칙 분석
- 새 프로젝트 디렉터리와 기준 문서 초안 구성
- 회의용 결정 항목과 권장 착수 순서 작성

## 후속 문서로 반영 완료

- 사용자가 재기획안 본문을 직접 전달하여 `docs/PROJECT_PROPOSAL.md`에 정리했습니다.
- 범위·플랫폼·추구미·촬영 조건·역할은 `docs/MVP_SCOPE_REVIEW.md`와 `docs/DECISIONS.md`에서 계속 관리합니다.

## 회의 후 작업

1. `docs/DECISIONS.md`에 확정 사항 반영
2. 최종 제안서와 프로젝트 브리핑 동기화
3. 아키텍처 및 API·데이터 계약 구체화
4. 선택한 기술 스택의 실행 가능한 최소 골격 생성
5. 1차 데이터 조사와 베이스라인 실험 계획 작성
