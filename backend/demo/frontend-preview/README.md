# MyFit:Core · 마피코 임시 모바일 웹

PRD 기반 UI 프리뷰입니다. Figma 파일은 아직 접근하지 못했으며 디자인 일치/완성본이 아닙니다. 외부 이미지나 사용자 사진 없이 CSS 도형을 사용합니다.

https://mafico-preview.vercel.app

- 홈/옷장/보관함/피드 탐색, 추구미별 고정 예시, 카테고리 필터, 좋아요, 가이드.
- 보관/오늘입기는 현재 탭 메모리에만 유지. 새로고침 초기화.
- Auth·업로드·날씨·AI·DB와 연결되지 않음. 제품 API로 오인하지 않도록 화면에 표시.
- Vercel 정적 public/ 배포. 백엔드 저장소에 이 프리뷰를 포함하지 않음.
- 브라우저 테스트: 로컬 검증 의존성과 Edge 설치 후 `npm test`. 실제 제품 프론트엔드가 아니라 백엔드 계약 참고용 과거 프리뷰입니다.
