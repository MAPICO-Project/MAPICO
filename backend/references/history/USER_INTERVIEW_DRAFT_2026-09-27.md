# 사용자 인터뷰 초안

> 내부 1차 검토용입니다. 팀 배포·실제 인터뷰 전에 문항과 표현을 한 번 더 다듬습니다.

## 인터뷰 목적

기능 선호를 묻는 것이 아니라 다음 가설을 검증합니다.

1. 실제로 옷 등록 피로가 서비스 사용을 막는가?
2. 사용자는 날씨·TPO·추구미를 어떤 순서로 생각하는가?
3. TPO 선택 한 번이 허용 가능한 마찰인가?
4. 타인의 OOTD를 내 옷으로 치환하는 기능이 재방문 동기가 되는가?
5. 위치·일정·옷 사진·OOTD 공개 중 어떤 정보에서 거부감이 생기는가?

## 대상과 규모

- 1차 탐색 인터뷰 6~8명
- 주 타겟 10~20대 4~5명
- 보조 타겟 대학생·직장인 2~3명
- 패션 관심도와 OOTD 공유 경험이 서로 다른 사람을 섞음

통계적 검증보다 문제와 언어를 발견하는 단계입니다. 이후 클릭형 프로토타입으로 15~20명 사용성 테스트를 분리합니다.

## 진행 순서: 25~30분

### 1. 최근 행동 회상

- 가장 최근에 외출복을 고른 상황을 처음부터 설명해 주세요.
- 가장 오래 고민했던 지점은 무엇이었나요?
- 날씨, 장소, 만나는 사람, 원하는 분위기 중 실제로 무엇을 먼저 확인했나요?
- 실패했다고 느낀 코디가 있었다면 왜 그랬나요?

### 2. 현재 해결법

- 평소 옷을 기억하거나 코디를 저장하는 방법이 있나요?
- 패션 앱·SNS·날씨 앱을 어떻게 오가나요?
- 디지털 옷장 앱을 써본 적이 있다면 어디에서 중단했나요?

### 3. 등록 행동 검증

- 옷 20벌을 앱에 등록해야 한다면 어느 정도까지 할 수 있을 것 같나요?
- 한 벌씩 찍는 방식과 2~6벌을 펼쳐 한 번에 찍는 방식 중 어떤 점이 부담인가요?
- AI 결과를 수정해야 한다면 몇 번의 수정까지 허용할 수 있나요?

### 4. TPO 검증

- 추천을 받기 전에 `일상/출근/데이트/격식/야외` 중 하나를 고르는 과정이 자연스러운가요?
- 이 다섯 개 중 겹치거나 빠진 상황이 있나요?
- 직접 선택과 캘린더 자동 판단 중 무엇을 선호하며, 왜 그런가요?
- 같은 추구미라도 등교와 면접에서 다르게 입고 싶나요? 어떤 부분이 달라져야 하나요?

### 5. 추구미·추천 검증

- 자신이 원하는 스타일을 어떤 단어 또는 이미지로 표현하나요?
- 5개 추구미 중 1~2개를 고르는 방식이 충분한가요?
- 추천 3개 중 선택하지 않는다면 가장 가능성 높은 이유는 무엇인가요?
- 추천 이유에서 날씨·TPO·추구미 중 무엇을 확인하고 싶나요?

### 6. Styling Mimic과 공개 범위

- SNS에서 본 코디를 따라 입으려다 포기한 경험이 있나요?
- 내 옷장의 비슷한 옷을 찾아준다면 어느 정도 비슷해야 쓸 만한가요?
- 본인의 옷 사진이나 OOTD를 공개하는 데 어떤 조건이 필요한가요?

## 피해야 할 질문

- “TPO 기능이 있으면 쓰실 건가요?”처럼 답을 유도하는 질문
- “AI가 정확하면 좋겠죠?”처럼 당연한 동의를 묻는 질문
- 미래 사용 의향만 묻고 최근 행동을 묻지 않는 방식
- 기능 설명을 길게 한 뒤 좋고 나쁨을 평가하게 하는 방식

## 인터뷰 후 기록할 것

- 실제 사용한 표현과 인용 가능한 문장
- 문제 빈도와 마지막 발생 시점
- 현재 대안과 지불한 시간
- TPO 직접 선택의 거부감
- 등록 허용량과 수정 허용량
- 공개·위치·일정 동의 경계
- 관찰 사실과 인터뷰어 해석을 분리

## 의사결정 연결

| 발견 | PRD 결정 |
|---|---|
| 사용자가 TPO를 먼저 떠올림 | 홈 상단에 TPO 선택 유지 |
| 선택 자체가 번거로움 | 기본값/최근값 + 선택 건너뛰기 |
| 캘린더 접근 거부감 큼 | 자동 연동 제외 유지 |
| 다중 촬영 배치가 더 어려움 | 단건 등록 병행·촬영 가이드 강화 |
| Mimic 관심이 낮음 | 소셜을 M2로 내리고 추천 완성도 집중 |
| 추구미 용어 이해가 낮음 | 텍스트보다 무드보드 중심 온보딩 |
