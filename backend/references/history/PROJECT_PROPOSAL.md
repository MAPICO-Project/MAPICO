# MyFit:Core 프로젝트 제안서

> 2026-09-21 전달받은 재기획안을 구조화한 로컬 정본입니다. 원본 PDF: `날씨기반코디추천-오가은.pdf`.

## 1. 기획 배경

기존의 실제 옷장 기반 날씨 코디 추천에 다음 세 가지를 결합합니다.

| 기존 한계 | 제안 솔루션 |
|---|---|
| 한 벌씩 촬영하는 등록 피로 | 다중 객체 검출·분할 기반 원샷 일괄 등록 |
| 전통 스타일 카테고리 중심 추천 | 15대 마이크로 추구미 온보딩과 가중치 반영 |
| 개인 유틸리티의 리텐션 한계 | OOTD 소셜 피드와 내 옷장으로 따라입기 |

## 2. 타겟

- 주 타겟: Aesthetic 문화와 OOTD 공유를 즐기는 10~20대
- 보조 타겟: 출근·등교 준비 시간을 줄이고 싶은 20~30대
- 핵심 페인: 등록 피로, 원하는 스타일과 추천의 불일치, 보유 의류 활용 영감 부족

## 3. 제품 목표

1. 최대 6벌 원샷 촬영과 자동 분리로 옷장 등록 허들을 낮춥니다.
2. 기상 데이터, 일정, 추구미를 결합해 개인화된 코디 3종을 제공합니다.
3. 추구미 OOTD 피드와 Styling Mimic으로 재방문·공유 동기를 만듭니다.

## 4. 제안 기능 범위

### 온보딩

- 소셜 로그인
- 15대 추구미 중 1~3개 선택 및 가중치 설정
- 다중 촬영 튜토리얼과 첫 옷장 등록

### 홈

- 위치 기반 기온·체감온도·강수확률·미세먼지
- 일정/TPO 입력
- 코디 추천 3종, 아이템 교체, 추천 설명
- 코디 확정 및 OOTD 기록

### 디지털 옷장

- 다중/단건 촬영과 앨범 업로드
- 객체별 배경 제거
- 카테고리·색상·패턴·추구미 태그 일괄 검토
- 착용 횟수, 수정·삭제, 매칭 아이템

### 스타일 스튜디오

- 직접 코디 조합
- OOTD 캘린더와 만족도
- 착용 및 미착용 통계

### 소셜 피드

- 추구미·날씨 필터
- 게시물, 좋아요, 댓글, 스크랩
- 내 옷장으로 따라입기 및 대체 아이템
- 공개/비공개 OOTD 게시

## 5. 제안 승인 조건

| 영역 | 제안 목표 | 상태 |
|---|---|---|
| 다중 등록 | 최대 6벌, 2초 이내 분할, 카테고리 정확도 90% 이상 | 측정 조건 정의 필요 |
| 일일 추천 | 추구미·날씨 조건을 반영한 코디 3종을 오전 7시에 제공 | 장애·지연 기준 정의 필요 |
| Styling Mimic | 타인 착장과 내 아이템의 매칭률 및 대체 추천 표시 | 매칭 정답·성공지표 정의 필요 |

## 6. 제안 KPI

| 구분 | 지표 | 목표 |
|---|---|---:|
| 획득·전환 | 온보딩 완료율 | 85% 이상 |
| 사용성 | 다중 의류 등록 완료율 | 75% 이상 |
| 인게이지먼트 | 일일 코디 채택률 | 40% 이상 |
| 리텐션 | D+7 / D+30 | 45% / 25% |
| 소셜 | 피드 스크랩·공유 전환율 | 20% 이상 |

이 수치는 현재 제품 목표값이며, 사용자 표본·측정 기간·이벤트 정의가 확정된 기준선은 아닙니다.

## 7. 역할

- AI: 검출·분할·속성 태깅, 추천, 유사도 검색, LLM 설명, 모델 서빙
- Backend: 인증, 이미지·메타데이터, 기상청 연동, 비동기 작업, 추천 저장, 소셜 API
- Frontend: 추구미 온보딩, 촬영 가이드, 일괄 편집, 추천 카드, 캘린더, 소셜 피드

## 8. 디자인 방향

- 키치한 시각 언어
- 기능이 많아도 핵심 행동은 단순하게
- 시각적 재미보다 등록·수정·추천 확정의 조작 수를 줄이는 것을 우선
