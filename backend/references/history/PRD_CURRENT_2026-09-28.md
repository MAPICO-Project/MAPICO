# 마피코 최신 PRD·회의 기록 정리

기준: 2026-09-28 사용자가 대화에 제공한 초기 제안서, 개발기능/역할/일정, 기능 ID 표, PRD 초벌, 9/26 통화 요약. 원문 전체 전사가 아닌 정리본이다. 링크의 Notion 본문은 직접 읽지 못했으며 PDF·스크린샷·디자인 이미지 파일 자체도 제공되지 않아 검토하지 않았다.

## 문서 해석 원칙

- 프로젝트명 **마피코**는 사용자 직접 확정 사항이다. MyFit:Core는 이전 명칭.
- 초기 제안서와 최신 기능명세가 충돌하면 최신 명세를 우선하되 회의의 '검토/확인 필요'를 확정으로 바꾸지 않는다.
- 취소선은 제외 방향으로 읽지만 같은 기능이 다른 부분에 잔존하면 충돌로 남긴다.
- 기존 에이전트의 M0.5 축소 권고는 팀 합의가 아니다. 제품 범위와 구현 단계 제안은 구분한다.

## 1. 제품 요약

실제 소유한 옷을 한 번에 등록하고 날씨와 취향에 맞춰 조합하며, 코디 보관·착용 기록·소셜 영감을 연결하는 AI 패션 서비스.

주 타깃은 패션/OOTD에 관심 있는 10~20대 여성, 보조 타깃은 준비 시간을 줄이고 싶은 20~30대 직장인·대학생이다. 디자인은 키치한 무드와 단순한 UX를 지향한다.

차별화 가설은 다중 의류 등록으로 등록 부담을 낮추고, 보유 의류 기반 추천과 따라입기를 제공하는 것이다. 경쟁 서비스의 현재 기능/단점, 평균 40분 등록 시간 등 초기 제안서의 시장 주장은 이번에 검증한 사실이 아니다. 에이클로젯을 참고하되 복잡도를 줄이고 필요한 기능을 재구성했다는 설명을 사용할 수 있으나 구체적인 비교 근거는 별도 확보해야 한다.

## 4. 제외/미래 확장

- 쇼핑몰 로그인·주문내역 스크래핑과 Google Calendar 연동은 역할표에 취소 표시. 뒤의 Supabase 설명에 남은 캘린더/쇼핑 서버 문구는 삭제 대상 후보다.
- 쿠팡 파트너스 링크, 쇼핑 플랫폼/브랜드 협업, 옷장 빈틈 기반 구매 추천, AI 트렌드 수집은 Future Work. 제휴 체결·수익 확보 사실이 아니다.
- 앱 매각은 가능한 사업 결과 아이디어이지 현재 수익 모델/개발 기능이 아니다.
- 댓글·주간 프리뷰·퍼스널컬러·체형은 초기 IA에는 있지만 최신 기능 표에 명확한 확정이 없어 현재 필수로 추가하지 않는다.
