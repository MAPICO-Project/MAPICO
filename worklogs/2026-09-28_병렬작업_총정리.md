## Supabase 연결 상태 — 최신

사용자 제공 프로젝트 식별자와 publishable key로 REST 응답을 확인했다. 프로젝트에는 아직 aesthetics 테이블이 없다는 PGRST205 응답이다. direct DB 호스트 db.<project-ref>.supabase.co는 DNS ENOENT로 실패했다. 제공된 DB 비밀번호 자체가 잘못됐다고 판단할 근거는 없다.

따라서 원격 SQL을 적용하지 않았다. Connect → Session pooler의 정확한 호스트·포트·사용자명 또는 연결 URL을 로컬 폴더에 추가하면 대상 스키마/이력을 읽고 검증된 migration을 적용할 수 있다. 연결 성공 시 기존 데이터 유무를 먼저 확인하며 초기화하지 않는다.
