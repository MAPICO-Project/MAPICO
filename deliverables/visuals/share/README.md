# 채팅방 공유 이미지

PNG 폴더는 채팅방에 이미지로 올리는 용도, SVG 폴더는 확대·편집·발표 자료에 넣는 용도입니다. 같은 번호는 같은 내용입니다. PNG는 2배 해상도, 흰 배경이며 도식 전체를 잘림 없이 담았습니다.

| 번호 | 내용 |
|---|---|
| 01 | 전체 사용자 여정 |
| 02 | 로그인과 온보딩 |
| 03 | 옷 등록과 AI 분석 |
| 04 | 날씨와 코디 추천 |
| 05 | 보관함과 OOTD |
| 06 | 피드와 따라입기 |
| 07 | 시스템 구성과 신뢰 경계 |
| 08 | AI 분석 처리 순서 |
| 09 | 따라입기 처리 순서 |
| 10 | 현재 추천과 AI 목표 |
| 11 | 전체 기능맵 |
| 12 | DB 전체 흐름 |
| 13 | ERD: 계정과 취향 |
| 14 | ERD: 옷 등록과 분석 |
| 15 | ERD: 추천과 OOTD |
| 16 | ERD: 피드와 따라입기 |

처음에는 01·11·12번을 올려 전체 흐름을 설명하고, 관심 있는 부분의 상세도를 이어 공유하면 됩니다.

상세 ERD는 실제 FK만 표시합니다. 실선은 식별 관계, 점선도 실제 FK인 비식별 관계입니다. 12번 요약도의 화살표는 업무 흐름으로 FK가 아닙니다. 반복된 테이블은 같은 테이블이며 public 테이블은 총 24개입니다. auth_users는 외부 auth.users를 나타냅니다.

이미지에 포함된 스냅샷 의류·미디어 ID는 실제 FK가 아닐 수 있습니다. 특히 mimic_source_items·mimic_candidate_items에는 job_id 외에 의류·미디어 대상 FK가 없습니다. 자세한 근거는 [ERD 문서](../ERD.md)를 확인하세요.

모든 자료는 팀 검토본입니다. 로컬 백엔드 구현은 실제 화면·AI·배포 검증 완료를 뜻하지 않으며 미결 정책은 그대로 유지합니다.
