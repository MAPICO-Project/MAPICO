# MyFit:Core · 마피코 디자인 참고 상태

- Figma: https://www.figma.com/design/XhhPLJSwkdCMAJgzqFLELf/마피코?node-id=10-2341
- 실제 프레임/레퍼런스 열람: 미완료. 일반 웹 접근 실패 및 연결된 Figma 도구 없음.
- 현재 UI는 사용자 제공 '키치한 디자인, 단순한 UX'와 PRD를 바탕으로 한 임시안이다. Figma 재현물이 아니다.
- 모바일 웹 우선은 사용자 확정. 임시 UI는 별도 apps/frontend-preview로 격리했다.
- 크림 배경/딥그린 액션/라일락·핑크 포인트, 종이 라벨, 간단한 의류 실루엣을 사용했다. 승인된 디자인 토큰이 아니라 교체 가능한 가정이다.
- 실제 사용자 사진/외부 패션 이미지는 사용하지 않고 CSS 도형 샘플만 표시한다.
- 데이터/AI/날씨/로그인 미연동 명시, 저장/좋아요는 탭 메모리 상태만 변경한다.
- Claude Opus 5.5가 읽기 전용 UI 방향 검토를 수행했으며, 전부 자동 채택하지 않았다.

브라우저 검증: 390px 및 1440px 캡처, 탭·추구미 전환·보관·오늘입기·필터·좋아요·dialog/Escape·초기화 확인. 스크린샷은 artifacts/ui-review에 있으며 Git 제외.
